# 🌙 Insomnia Killer

> **Transform your nights into restful sleep.** Insomnia Killer is an interactive web-based sleep wellness companion designed to monitor screen time, guide bedtime relaxation, and foster restorative sleep habits.

---

## ✨ Features

- 🕒 **Live Screen Time & Bedtime Clock**: Real-time counter monitoring your screen time with dynamic wellness reminders as the hour grows late.
- 🌌 **Automatic Midnight Mode**: Smooth transition into a starry, calming dark mode when midnight arrives or late hours are detected.
- 👁️ **Interactive Eye Relaxation Exercise**: Step-by-step guided visual exercises (Follow Dot, Eye Rolls, Blink Rest, and Palm & Rest) to alleviate digital eye strain.
- 🧘 **Guided Breath Meditation**: Calming breathing circle visualization with guided inhale/hold/exhale phases.
- 🎵 **Ambient Audio Synthesizer**: Built-in soundscapes using the Web Audio API—enjoy *Ocean Waves*, *Rainfall*, *Forest Breeze*, and *Cosmic Drift* with zero external audio assets required.
- 📊 **Sleep & Screen Time Dashboard**: Log and visualize your daily screen time and sleep patterns across the week.
- 📑 **Personalized Sleep Health Report**: Actionable insights, sleep scores, and tailored advice based on your logged habits.
- 💡 **Sleep Awareness Guide**: Science-backed tips and strategies for overcoming insomnia and optimizing circadian rhythms.

---

## 🚀 Getting Started

No dependencies or build steps required! Simply run the project in any modern browser:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/SadhanaArul/Insomnia_killer.git
   cd Insomnia_killer
   ```

2. **Open in browser:**
   - Double-click `index.html`, or
   - Serve using VS Code Live Server or any static file server:
     ```bash
     npx serve .
     ```
